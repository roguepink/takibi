# ひとくべ — 設計のまとめ(2026-10-25 構成係・デザイン係・UI/UX係)

姉妹アプリ「一灯」(rosoku)・「one candle」(kyandoru)の決まりに そろえ、焚き火ならではの所だけ 足した。

## 名前(デザイン係)
3つ考えた:
1. **ひとくべ** — 「薪を ひとつ くべる」。火を絶やさないように 少しずつ足していく、焚き火のいちばん静かな時間の言葉。
   短い動画を つぎつぎ足して 火を絶やさない、このアプリの しくみ そのもの。ひらがなで やわらかく、だれでも読める。
2. 火守(ひもり) — 火の番をする人。凛として良いが、読みにくく、少し かたい。
3. 夜火(よび) — 夜の火。短いが「呼び」と まぎれる。

→ **ひとくべ** にした。一灯(漢字2字)と並べても 姉妹らしく、ちがいも出る。ROGUE PINK は「ととのえる」の いちばん下の クレジットだけ。

## 構成係(しくみ)
- ファイル: `js/app.js`(画面の動き・おやすみ・覚える)/ `js/fire.js`(動画をつなぐ場面)/ `js/sound.js`(焚き火の音・まわりの音)/
  `js/music.js`(曲。一灯と同じ。いまは曲なし)/ `js/scenes.js`(リーダーが作る場面のリスト)。ビルドなし・importmap なし。
- **ランダムにつなぐ**: `<video>` を2つ重ね、終わる 0.4秒前に 次を頭から流して 0.4秒で重ねる。
  - どの動画も「同じ絵で始まって終わる」ので、重ねるだけで つなぎ目が見えない(白くとばしたり 暗くしたりはしない)。
  - 順番は ランダム。直前の数本(4本なら2本、10本なら3本)は さける → 同じ映像が すぐ出てこない。
  - 次の動画は 見えない所で 一瞬だけ流して止めておく(iPhone は こうしないと 最初の絵まで読まない)。
  - 次が まだ読めていないときは、いまの動画を もう一度くり返す(どの動画も くり返して つなぎ目が出ない作り)。止まって見えるより良い。
  - 1秒ごとに 止まっていないか見る。止まっていたら流しなおす。5秒うごかなければ ほかの動画へ。読めない動画は とばす。全部だめなら 静止画。
- **場面の切りかえ**: 1.4秒で黒へ → 入れかえ → 2.6秒で もどる。まわりの音(森⇄波)は 6秒かけて 重ねて入れかえる。焚き火の音も 場面に合ったもの(山=乾いた薪・海=落ち着いた音)に 同じく6秒で入れかわる(音のまとめ係 2026-10-25。docs/sound.md)。
- **おやすみの終わり**: いまの動画が終わったら end の動画(火が小さくなって熾火)へ同じように重ね、最後の絵で止める →
  15秒で真っ黒 → 音も 消える → 描くのを止め、画面つけっぱなしもやめる(電池)。
  最後の1分は 音を少し小さく、火も ほんの少しだけ暗く(急に変わらないように)。
  end が読めないときは そのまま暗くする(25秒の保険)。
- **音**: Web Audio。`sound/sounds.json` だけを読む。焚き火の音(fire のくり返し + pops のはぜる音)と まわりの音(yama/umi)を 別々の大きさで。
  - くり返しは 毎回ちがう所から始める。pops は ふつう2〜9秒おき、ときどき続けて2〜3回、まれに長い間。大きさ・左右・高さを 少しずつ変える。
  - 音のファイルは 使う場面のぶんだけ読む(古い iPhone のメモリのため)。sounds.json が無いときは「音」のボタンを出さず、音なしで動く。
- **電波なし**: `sw.js`。本体は はじめに覚える。動画・音は 一度使ったものだけ覚える。
  動画は ブラウザが少しずつ読む(Range)ので、ネットにつながるときは ふつうにネットから、つながらないときは 覚えた動画から切りだして渡す
  (一灯は 動画を電波なしで出せなかった。そこを直した)。古い動画は js/scenes.js の MEDIA_V とくらべて 自動で消す。

## デザイン係(見た目)
- 夜・癒し。画面にあるのは ほとんど 火だけ。文字は最小限、やさしい日本語。白い色・すりガラス・カタカナ用語は使わない(一灯と同じ)。
- 色: 文字 灰がかった生成り #C8B497 / 選んでいるもの 熾火のだいだい #E3964E / タイマーの印とクレジット くすんだ紅 #B36A5A / 板 こげ茶 88%。
- 文字: Zen Old Mincho(一灯と同じ。あとから読みこむ → 通信が遅くても ページは先に出る)。
- はじめの画面: 火をつける前の場面が 暗く うっすら見え、名前「ひとくべ」が たて書き。「ふれると、火がともります」。
- 横長の画面(パソコン・タブレット): 縦の動画を まん中に、左右は 同じ動画の 火のあたりを 大きくぼかして暗くした絵で うめる。境目は 影で なじませる。
- 「ととのえる」: 大きさ 3段(火のあたりを中心に拡大)/ 明るさ 5段(はじめは 4番目)/ 色あい 3段(そのまま・あたたかく・もっと)。
  夜に使うので「白っぽく」は入れず、あたたかい方だけ。
- アイコン・紹介画像は 仮(組んだ薪と炎の絵)。リーダーが 本物の絵で作り直す。

## UI/UX係(使い心地)
- 一灯と同じ: ふだんは何も出さない → ふれると 下にボタン → 6秒(板を開いていれば15秒)で ゆっくり消える。消えかけでも押せる。同じボタンをもう一度で 板が閉じる。
- ボタンは4つ(+曲があれば5つ): **場所 / 音 / おやすみ / ととのえる**(曲)。文字を必ず そえる。
  - 場所: 2つの絵(山の焚き火・海の焚き火)。選ぶと 板も操作も消えて、新しい場所が ゆっくり出てくる。操作が出ているときだけ 左右にはらっても変わる。
  - 音: 「音を止める/音を出す」と、すべり棒2本「焚き火の音」「森の音(海では 波の音)」。
  - おやすみ: なし / 5 / 10 / 15 / 30 / 45 / 60 / 90分。一灯の「お線香一本」は 焚き火に合わないので 45分に。「時間がくると、火がゆっくり小さくなって、熾火になります」。
  - ととのえる: 上のほか「火を消す」「画面いっぱいにする(iPhone 以外)」、ホーム画面に入れる案内、LINE・画面が消えるときの案内。
- 火をつける・もう一度つける は 指を離したとき(pointerup)。iPhone の Safari は ボタン以外では click を出さないことがある(一灯で「開けない」と言われた原因)。
  この最初のタッチで 動画・音・画面つけっぱなしを 始める(スマホの決まり)。
- はじめの3回だけ「画面にふれると、場所や音をえらべます」。
- アプリを閉じたら 音も動画も すぐ止める。もどったら また流す(iPhone で 音が出ないときは、画面にふれれば また鳴る)。
- おやすみの後は 真っ黒。ふれると「もう一度、火をつける」だけ出る(10秒で消える。暗い寝室で 光りつづけないように)。
- 設定は localStorage(`takibi-v1`)に覚える: 場所・大きさ・明るさ・色あい・音の大きさ・音を出すか。LINE の中などで覚えられなくても 止まらない。
- パソコン: マウスを動かすと操作が出る。← → で場所、スペースで音、Enter で火をつける。
- 確かめ用の隠し設定: `?sleep=20`(火をつけて20秒で おやすみ)、`?scene=umi`(海から始める)。
